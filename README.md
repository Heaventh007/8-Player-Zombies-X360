# 8-Player-Zombies-X360
This plugin allows for 8 players to play in zombies on Xbox 360.

# How to use
- Load up Black Ops 2 Zombies
- Inject the plugin
- Invite 3 other friends in the lobby
- Start the game
- Invite the rest

### If you're using a tool, or menu that has force start, you can just invite everyone.

# Notes
This plugin is a bit unfinished, if you'd like to contribute to it go for it.
